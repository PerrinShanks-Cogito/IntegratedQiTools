Run an ANOVA

Paste measurements for two or more groups, such as waiting times by site or length of stay by ward, and test whether their averages really differ or just vary by chance. Everything runs in your browser, so your data is never uploaded.

Your data

Either two columns, a group name and a value, with one row for each measurement; or one column of values for each group, with the group names in the first row. You need at least two groups.

Test settings

The standard test assumes each group’s values are about as spread out as the others’. Welch’s version doesn’t. “Choose for me” uses Welch’s when the spreads look different.

What it does: a one-way analysis of variance (ANOVA) asks whether the averages (means) of two or more groups differ by more than chance alone would explain. It compares how far the group means sit from each other with how much the values vary within each group. The p-value is the chance of seeing differences at least this large if the groups really had the same mean; a p-value below your significance level is taken as evidence of a real difference.

Which groups differ: a significant ANOVA says at least one group is different, not which. The pairwise comparisons then test each pair of groups, with the p-values adjusted (Holm’s method) so that making many comparisons doesn’t throw up false alarms. Welch’s ANOVA uses Welch’s t-test for each pair.

Things to check: ANOVA works best when the values in each group are roughly symmetrical and each group has a reasonable number of values (ideally 10 or more). The standard test also assumes the groups are similarly spread out; the spread check (Brown–Forsythe test) flags when they aren’t, and Welch’s ANOVA is then the safer choice. Each value should be a separate, independent measurement. ANOVA looks at a snapshot, not change over time, so use a run chart or SPC chart to see whether a process is stable, and a box and whisker plot to see the shape of each group. A real difference isn’t always a large or important one: look at the size of the gap, too.
