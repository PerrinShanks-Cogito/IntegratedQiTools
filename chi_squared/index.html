Run a chi-squared test

Paste counts, such as patients seen on time or late on each ward, and test whether the split really differs between groups or just varies by chance. Or compare one set of counts with the split you expected. Everything runs in your browser, so your data is never uploaded.

Your data

Either a table of counts, with the groups down the first column and a column of counts for each category; or one row for each person or event, with a column for their group and a column for their category (add a third column of counts if each row stands for more than one). To compare with an expected split, paste a column of categories and a column of counts, with an optional third column of expected counts or percentages.

Test settings

Compare groups asks whether the split across categories is the same in every group. Compare with an expected split asks whether one set of counts matches the split you expected: equal across categories, unless you add a column of expected counts.

What it does: a chi-squared test works on counts: how many people, events or items fall into each category. Comparing groups (a test of independence) asks whether the split across categories is the same in every group, for example whether the share of patients assessed late is the same on each ward. Comparing with an expected split (a goodness of fit test) asks whether one set of counts matches what you expected, for example whether falls are spread evenly across the days of the week. Both compare the counts you have with the counts you would expect if there were no difference. The p-value is the chance of seeing a gap at least this large by chance alone; a p-value below your significance level is taken as evidence of a real difference.

Which cells stand out: a significant result says the pattern differs somewhere, not where. The adjusted residual for each cell measures how far its count is from the expected count, allowing for the size of its row and column. Cells beyond the critical value (adjusted for the number of cells, so that checking many cells doesn’t throw up false alarms) are marked as standing out. Cramér’s V (or Cohen’s w for an expected split) shows how strong the difference is, from 0 for none upwards.

Things to check: use actual counts, not percentages or averages, and count each person or event once. The test is reliable when the expected counts are large enough: none below 1 and no more than one in five below 5. If they are smaller, combine categories or collect more data; for a 2 × 2 table, Fisher’s exact test is used instead. The chi-squared test looks at a snapshot, not change over time, so use a run chart or SPC chart to see whether a process is stable. A real difference isn’t always a large or important one: look at the percentages, too.
