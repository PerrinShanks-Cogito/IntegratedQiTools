How to read it: each bar's length shows the amount for one category, so longer bars mean more. The value axis always starts at zero so bars can be compared fairly. Use side-by-side bars to compare groups within each category, and stacked bars to show how each total is made up.

Choosing the right chart: to find the few causes behind most of a problem, sort largest first or use a Pareto chart. To see how a measure changes over time, use a run chart or SPC chart instead. A bar chart can't show whether a change is real or just normal variation.
