Run chart builder

Paste dates and values. You'll get a run chart checked against the four run chart rules from Perla, Provost and Murray's run chart paper (also in the NHS guide to creating and interpreting run and control charts), with a plain-English reading of what the chart shows.

Copy two columns from Excel (date, then value) and paste them here. A header row is fine. One column of values on its own also works.

      Check how your data was read

      Rules, wording and the limits for the number of runs follow Perla, Provost and Murray, The run chart: a simple analytical tool for learning from variation in healthcare processes (BMJ Quality & Safety, 2011), adapted from Swed and Eisenhart, for 10 to 60 useful observations; above 60 a normal approximation is used. The same four rules appear in the NHS Institute for Innovation and Improvement's A guide to creating and interpreting run and control charts (2009), which uses the terms special and common cause; following Provost and Murray, this tool keeps those terms for control charts.
